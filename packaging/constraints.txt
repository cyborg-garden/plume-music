# Pinned versions for the release build and the packaging spike.
#
# Use:  python -m pip install -c packaging/constraints.txt ".[play,midi,notes]"
#
# Covers Python 3.11 and 3.12 on:
#   macOS 14 or newer on Apple Silicon
#   macOS 13 or newer on an Intel Mac
#   Linux x86_64 with glibc 2.28 or newer
#   Windows x64
# Anywhere else, install without -c.  python-rtmidi 1.5.8 has no wheel for
# Python 3.13 or newer, and onnxruntime 1.32.0 has none for macOS 13 on Apple
# Silicon, so an install with these pins fails there.
#
# These are the versions the `tests` workflow installs on a green run on main,
# on macOS, Linux and Windows.  numpy and scipy have one pin per Python, because
# their current releases need Python 3.12.
#
# The exception is an Intel Mac.  It gets onnxruntime 1.23.2, the newest release
# with an Intel Mac wheel, and the four packages it brings that 1.32.0 does not.
# No `tests` run has used those five; the `constraints` workflow installs and
# imports them on an Intel runner, and that is all.  Run the suite on an Intel
# Mac before a build for one ships.
#
# To move a pin: find a green `tests` run on main, read the version from its
# install log on all three systems, and write it here.  Then run
# `python packaging/check_wheels.py`, which asks PyPI whether every pin has a
# wheel for every system and Python listed above, and install with the pins
# using `--only-binary :all:` on each of those systems.  Apart from the Intel Mac
# lines, a version no green run has used does not belong in this file.
